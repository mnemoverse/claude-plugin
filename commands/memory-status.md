description: Show what is stored in long-term memory, counts and domains
---

Report the current state of the connected Mnemoverse memory:

1. Call the stats tool and summarise: how many memories, which domains, anything notable about the distribution.
2. List the newest few memories via the recent-list tool so the user sees what sessions have been saving lately.
3. Keep it to a short table plus one or two observations. No advice unless something looks wrong, such as an empty store after weeks of use, which usually means recall-before-acting is not happening; in that case point at the agent-memory-discipline skill bundled with this plugin.
4. If no memory tool is connected, say so and point at the /mnemoverse:setup instructions (the bundled setup skill).
